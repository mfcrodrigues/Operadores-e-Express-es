# Operadores-e-Express-es
Operadores e Expressões
Nesta atividade, vamos praticar como o computador faz cálculos, compara valores e toma decisões lógicas. Utilize os exemplos das imagens da aula para resolver os 10 desafios abaixo.

Envio do Arquivo:
Salve seus códigos em um único arquivo .html ou em um documento de texto e envie aqui no Moodle para registro de sua presença.

Como realizar: Para cada desafio, escreva o código dentro de um arquivo HTML entre as tags <script> e </script>. Use o console.log() ou alert() para ver os resultados.
1. Calculadora de Resto
Crie duas variáveis numéricas. Use o operador de Resto da Divisão (%) para exibir o resto da divisão do primeiro número pelo segundo.

2. O Poder da Exponenciação
Declare uma variável base e outra expoente. Use o operador ** para calcular a potência e exiba o resultado.

3. Incremento Pré e Pós
Crie uma variável i = 10. Exiba no console o valor de ++i e depois o valor de i++. Explique (em comentário no código) por que os resultados aparecem diferentes.

4. Verificador de Igualdade
Peça dois números ao usuário via prompt e use o operador == para exibir um valor booleano (true/false) indicando se eles são iguais.

5. Maior ou Menor?
Compare se 15 é maior ou igual (>=) a 20 e exiba o resultado lógico na tela usando document.write.

6. Diferença Estrita
Crie um programa que verifique se o nome digitado pelo usuário é diferente de (!=) "Admin".

7. Operador E (&&) - Acesso Permitido
Crie duas variáveis: temIngresso = true e estaNaLista = false. Use o operador && para verificar se a pessoa pode entrar (precisa dos dois como true).

8. Operador OU (||) - Meia Entrada
Um aluno tem direito a meia entrada se for "Estudante" OU se tiver "menos de 21 anos". Crie essas variáveis e use || para validar o direito.

9. Negação Lógica (!)
Crie uma variável chuva = true. Use o operador de negação para exibir o valor invertido e diga ao usuário se "hoje o sol vai brilhar".

10. Desafio Mestre: Expressão Combinada
Resolva a expressão lógica e exiba o resultado: (10 > 5) && (7 < 3) || !(5 == 5).
Dica: Siga a precedência de avaliação vista nos slides!
